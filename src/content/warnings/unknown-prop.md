---
title: Предупреждение о неизвестном пропе
---

Предупреждение о неизвестном пропе появится, если вы попытаетесь отрендерить DOM-элемент с пропом, который React не распознаёт как допустимый DOM-атрибут/свойство. Вы должны убедиться, что в ваших DOM-элементах нет лишних пропов.

Есть несколько вероятных причин появления этого предупреждения:

1. Используете ли вы `{...props}` или `cloneElement(element, props)`? При копировании пропов в дочерний компонент убедитесь, что вы случайно не передаёте пропы, предназначенные только для родительского компонента. См. распространённые исправления этой проблемы ниже.

2. Вы используете нестандартный DOM-атрибут в нативном DOM-узле, возможно, для представления пользовательских данных. Если вы пытаетесь прикрепить пользовательские данные к стандартному DOM-элементу, рассмотрите использование пользовательского атрибута данных, как описано [на MDN](https://developer.mozilla.org/ru/docs/Web/HTML/Using_data_attributes).

3. React ещё не распознаёт указанный вами атрибут. Вероятно, это будет исправлено в будущей версии React. React позволит вам передавать его без предупреждения, если вы напишете имя атрибута в нижнем регистре.

4. Вы используете React-компонент без заглавной буквы, например `<myButton />`. React интерпретирует его как DOM-тег, потому что трансформация JSX в React использует соглашение о верхнем и нижнем регистре для различения пользовательских компонентов и DOM-тегов. Для ваших собственных React-компонентов используйте PascalCase. Например, напишите `<MyButton />` вместо `<myButton />`.

---

Если вы получаете это предупреждение, потому что передаёте пропы вроде `{...props}`, ваш родительский компонент должен «потребить» любой проп, который предназначен для родительского компонента, а не для дочернего. Пример:

**Плохо:** Неожиданный проп `layout` передаётся тегу `div`.

```js
function MyDiv(props) {
  if (props.layout === 'horizontal') {
    // ПЛОХО! Потому что вы точно знаете, что "layout" — это не проп, который понимает <div>.
    return <div {...props} style={getHorizontalStyle()} />
  } else {
    // ПЛОХО! Потому что вы точно знаете, что "layout" — это не проп, который понимает <div>.
    return <div {...props} style={getVerticalStyle()} />
  }
}
```

**Хорошо:** Оператор расширения можно использовать для извлечения переменных из пропов и помещения оставшихся пропов в переменную.

```js
function MyDiv(props) {
  const { layout, ...rest } = props
  if (layout === 'horizontal') {
    return <div {...rest} style={getHorizontalStyle()} />
  } else {
    return <div {...rest} style={getVerticalStyle()} />
  }
}
```

**Хорошо:** Вы также можете присвоить пропы новому объекту и удалить ключи, которые вы используете, из нового объекта. Убедитесь, что вы не удаляете пропы из исходного объекта `this.props`, поскольку этот объект следует считать неизменяемым.

```js
function MyDiv(props) {
  const divProps = Object.assign({}, props);
  delete divProps.layout;

  if (props.layout === 'horizontal') {
    return <div {...divProps} style={getHorizontalStyle()} />
  } else {
    return <div {...divProps} style={getVerticalStyle()} />
  }
}
```
