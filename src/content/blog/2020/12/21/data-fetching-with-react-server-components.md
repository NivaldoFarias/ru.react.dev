2020 год был долгим. Под конец года мы хотели поделиться специальным праздничным обновлением о наших исследованиях **React Server Components** с нулевым размером бандла.

</Intro>

---

Чтобы представить React Server Components, мы подготовили доклад и демо. Если хотите, вы можете ознакомиться с ними во время праздников или позже, когда работа возобновится в новом году.

<YouTubeIframe src="https://www.youtube.com/embed/TQQPAU21ZUw" />

**React Server Components всё ещё находятся на стадии исследования и разработки.** Мы делимся этой работой в духе прозрачности и для получения первоначальной обратной связи от сообщества React. Для этого будет достаточно времени, поэтому **не чувствуйте себя обязанными разбираться прямо сейчас!**

Если вы хотите ознакомиться с ними, мы рекомендуем следующий порядок:

1. **Посмотрите доклад**, чтобы узнать о React Server Components и увидеть демо.

2. **[Клонируйте демо](http://github.com/reactjs/server-components-demo)**, чтобы поиграться с React Server Components на своём компьютере.

3. **[Прочтите RFC (с FAQ в конце)](https://github.com/reactjs/rfcs/pull/188)** для более глубокого технического разбора и предоставления обратной связи.

Мы будем рады услышать ваши отзывы в RFC или в ответах на странице [@reactjs](https://twitter.com/reactjs) в Twitter. Счастливых праздников, берегите себя и до встречи в следующем году!
